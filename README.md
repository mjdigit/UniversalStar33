# UniversalStar33

UniversalStar33 is a compact ortholinear lowprofile keyboard with 33 keys and a TPS43
touchpad.

UniversalStar33は小型のタッチパッドを中央に配置した、33キーオーソリニアレイアウトのコンパクトなロープロファイルキーボードです。

## Parts List

### Parts need to be prepared/purchased

|Part|Quantity|Remarks|
|---|---|---|
|Wired controller board<br/>コントローラボード|1|RP2040-Zero (w/ pin headers)|
|Choc socket|33|e.g. Kailh PG1350 KeySwitches Contact (CPG135001S30)|
|Choc V2 switch|33||
|1U Keycap|33||
|Touchpad Module TPS43 (or clone module)|1||
|Polycarbonate sheet for touchpad (0.5mm thickness)<br/>or any other sheet for putting on the touchpad|1|Need to be cut to suit TPS65|
|PET double-sided adhesive sheet<br/>両面接着シート|1|Need to be cut to suit TPS65|
|M2 Spacer (3.5mm-)|4|Spacers for between main plate and touchpad mounting plate|
|M2 Spacer (5.0mm)|6|Spacers for between top plate and bottom plate.|
|M2 screw (3.0-3.5mm)|8|-|
|M2 screw (3.5-4.0mm)|12|-|
|FPC cable (6pin, 0.5mm pitch, 50mm length)|1|-|
|Rubber feet<br/>ゴム足|6|-|
